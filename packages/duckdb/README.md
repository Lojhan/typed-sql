# @typed-sql/duckdb

DuckDB grammar, catalog snapshots and exact native value policies for typed-sql.
Applications import `sql` from this package; database drivers are explicit application dependencies.

See the canonical [grammar architecture](https://github.com/Lojhan/typed-sql/blob/main/docs/concepts/architecture.md)
and [execution adapter guide](https://github.com/Lojhan/typed-sql/blob/main/docs/guides/adapters.md).

# @typed-sql/migrations

Driver-neutral SQL/TypeScript migration lifecycle, immutable execution plans, blocking drift checks and inspected recovery.

```sh
pnpm add -D @typed-sql/migrations @typed-sql/cli
```

Applications install an explicit grammar migration adapter and its driver. See [database migrations](https://github.com/Lojhan/typed-sql/blob/main/docs/guides/migrations.md) for configuration, global/local checks, manual schema reconciliation and a fresh-database workflow.

# typed-sql for VS Code

The experimental VS Code integration uses the application-installed `@typed-sql/language-server`.

Install [typed-sql from Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=lojhan.typed-sql)
and follow the canonical [editor setup guide](https://github.com/Lojhan/typed-sql/blob/main/docs/guides/editors.md).
The preferred native SDK mode keeps VS Code's built-in TypeScript extension enabled and uses one
language provider. Standalone proxy mode has separate provider-selection requirements.

For development builds and packaged-host tests, see
[CONTRIBUTING.md](https://github.com/Lojhan/typed-sql/blob/main/CONTRIBUTING.md).
